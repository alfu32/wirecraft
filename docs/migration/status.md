# Current migration status

Wirecraft 0.3.0 is a working Linux migration milestone, **not a complete replacement**. The source remains unchanged and its existing desktop/MCP server remains running. Source revision: `7d392d3a0e30b86445e00e7c03032a5188b26593` (Threadworks 2.6.7). Destination origin is `git@github.com:alfu32/wirecraft.git`, branch master. Release policy: regular Conventional Commits and pushes, patch/minor tags only; major versions belong to the user.

- Current list and legacy map .orch files, unknown payload fields and binary data. All 45 source projects load. Atomic saves, topology repair, transactional entity/link/hierarchy mutations, typed ports, status history, inherited settings, revision conflicts and undo/redo.
- GPUI canvas with spatial node/edge culling, revision-cached routes, virtual hierarchy, select/multiselect/window selection/drag, node/type/link creation, link hit-testing, focused hierarchy navigation, pan/zoom/Fit, five text sections and JSON entity properties. Clipboard fragments and alignment/distribution. Viewport/selection/section, applied graph and unapplied editor drafts recover across restart. Dirty polling is constant time using undo state identities rather than whole-document serialization.
- Embedded source archetypes with import/save and fresh entity/type/link IDs; typed network graphs/reports; Markdown fiches; real free-size SVG, PNG and vector PDF diagrams.
- Literal file-export/multi-tech generation, source maps, staged output with path/collision checks and refusal to overwrite nonempty directories. C17 graph generation additionally supports typed data/error flow, structs, nested composites, service function pointers, setup/run phases, self-feedback, shutdown and source mapping. Remaining C capabilities/templates and other language graph compilers are pending.
- Original 19 MCP tool names, five resources and two prompts, plus 17 Wirecraft extensions for project/workflow/LSP/build operations. HTTP and stdio use the same application services. Reduced command/technology catalogs report actual availability.
- Real supervised clangd: negotiation, open/change/close, versions, UTF-8/16/32 conversion in both directions, diagnostics, document/workspace requests, cancellation, stale replies, explicit restart and crash handling. Desktop checks standalone selected source and generated C17 topology, maps diagnostics to authored node sections and reveals the clicked source location.

- Explicit Java Preferences XML import into new JSON settings. Indentation/tool configuration active; appearance/panel values archived; identity/AI nodes excluded. Linux package/install scripts, desktop/MIME/icon resources and CI configuration.
